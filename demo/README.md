# Functionality demonstration

`byte_club_demo.mp4` is a silent, captioned walkthrough assembled from actual browser screenshots of the running Gradio applications and real Gemini responses. Pauses are condensed. It is not an uninterrupted screen recording. The captures show the revised interface, with Patch selected.

The demonstration covers business questions grounded in both documents, missing-contact collection, short-term memory, a successful model-requested lead tool, its arguments and receipt, feedback logging, unknown-question handling, and the C4 configuration interface. Contacts use `example.com` and are synthetic.

The screenshot files and subtitles are retained so the video is auditable and can be rebuilt with `authoring/make_video.py`. The full model and tool outputs are recorded separately in the notebooks and results folders.
